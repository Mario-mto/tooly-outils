# Outils Tooly pour Claude Code

Marketplace interne de Tooly. Il contient un plugin :

- **coach-automatisation** : un coach qui t'accompagne étape par étape pour transformer une
  tâche répétitive en automatisation, et t'apprend ce que tu fais en chemin.

## Installer

Dans Claude Code (desktop ou terminal), ajoute le marketplace `Mario-mto/tooly-outils`, puis
installe le plugin `coach-automatisation`. Dans le terminal :

```
/plugin marketplace add Mario-mto/tooly-outils
/plugin install coach-automatisation@tooly-outils
```

Relance ensuite la session et tape `/coach-automatisation:coach`.

## Mettre à jour

```
/plugin marketplace update tooly-outils
```
